# Plugin template

1. Copy this folder to `public/plugins/<your-id>/`.
2. Edit `plugin.json` — `id`, `name`, `version`, `author`.
3. Edit `index.js`.
4. Branch: `plugin_<your-id>_<version>`  
   Example: `plugin_hello-ledger_0.1.0`
5. Open a pull request into `main`.

Do not add `_template` to `public/plugins/index.json`. Only ship plugins that are ready.

Local drop-in (no PR): copy the folder next to `Tyria Ledger.exe` under `plugins/`.

Wiki: https://github.com/NolvusMadeIt/tpledger/wiki/Plugin-Guide
